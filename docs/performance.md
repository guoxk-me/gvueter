# Performance

Status: Starter baseline; feature-specific budgets are planned.

The starter mounts a single public route after one bounded runtime-config request. The default build omits the PWA worker. The optional PWA build precaches static shell assets and leaves API/configuration requests on the network.

Old dashboard, table, menu, and appearance budgets no longer describe the application and were removed. Measure new feature bundles and interactions before setting release-blocking thresholds.
