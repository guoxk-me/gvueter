# Security policy

This frontend foundation has no active login or business endpoints. Deployment inputs are public browser settings; never put credentials in `runtime-config.json` or Vite environment variables. Future backend operations must enforce authorization server-side.

Report a suspected vulnerability privately through the repository's [GitHub Security Advisory](https://github.com/guoxk-me/gvueter/security/advisories/new). Include the affected commit, reproduction, impact, and any proposed mitigation without publishing credentials or personal data.
